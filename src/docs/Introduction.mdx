# HMI Storybook

React components whose visuals come **only** from Figma Variables.

## How the tokens flow

1. A designer edits a variable in Figma.
2. The **HMI Variables → GitHub** plugin (or the Figma REST API on Enterprise) writes `tokens/figma-variables.json` to GitHub.
3. GitHub Actions runs `npm run tokens:build`, which generates `src/tokens/tokens.css`, rebuilds Storybook, and deploys it.

## Modes

Each Figma collection with more than one mode becomes a toolbar switch and a `data-*` attribute:

| Figma collection | Modes | HTML |
| --- | --- | --- |
| Theme | Light, Dark | `<html data-theme="dark">` |
| Density | Touch, Compact | `<html data-density="compact">` |

Components only use semantic tokens (`--color-action-primary-default`, `--size-control-height`, …), never primitives or hex values. Rename a variable in Figma and you also rename its CSS variable, so rename with care.

See **Foundations / Figma Variables** for the live token table.
